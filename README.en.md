# LyricsX TB

[简体中文](README.md) · **English**

An unofficial Touch Bar edition based on [LyricsX Next](https://github.com/wzk112/LyricsX-Next).

[Download the app for Apple Silicon](https://github.com/MushroomKiiing/LyricsX-TB/releases/download/v2.0.43-tb.5/LyricsX-TB-2.0.43-tb.5-arm64.zip) · [Release page](https://github.com/MushroomKiiing/LyricsX-TB/releases/tag/v2.0.43-tb.5)

## Improvements over LyricsX Next

- **Touch Bar:** background lyrics, full-width display and touch switching, with side-by-side translation and scrolling.
- **Playback and artwork:** improved NetEase playback sync and optional high-resolution artwork matching (NetEase only).
- **Startup and privacy:** launch with NetEase and privacy explanations for optional online features.
- **Cache management:** optional automatic caching, cache cleanup and a lyric library.
- **Settings and appearance:** settings search, clearer categories, and improved translation and styling controls.

## Installation

Download **LyricsX-TB-2.0.43-tb.5-arm64.zip**, unzip it, and move **LyricsX TB.app** to Applications. No Codex, source code or developer tools are needed. Enable lyrics in Settings → Touch Bar.

Apple Silicon · macOS 26+ · Not notarized by Apple.
