# 相对 LyricsX Next 的改动

比较基线：wzk112/LyricsX-Next 提交 54561db8c06e1abfefbe7aa0f0c2bc26cff94eeb（2.0.43 开发线）。以下说明本次分支的最终实现，不代表上游没有其他功能。

| 项目 | 上游/此前状态 | LyricsX TB |
|---|---|---|
| Touch Bar 控制 | 上游前台组件与实验性后台入口；此前本机还运行独立助手 | 由主应用统一拥有和配置，去掉外部助手依赖 |
| 全宽与普通模式 | 需另外切换，之前试验出现黑条及控制权争抢 | 单一控制器；空白也可轻触退出全宽；普通模式仍有歌词及系统控制条；闲置 1–15 秒后恢复 |
| 宽度 | 试验中全宽可视区域过窄 | 跟随实际宿主宽度布局；本机测得普通约 620 pt、全宽约 988 pt，并非硬编码所有硬件 |
| 文字 | 逐字绿色高亮等原设计 | 固定 15 pt 白色常规字；左右双语，独立滚动 |
| 控件取舍 | 原 Touch Bar 包含封面/播放切歌等控件 | 本分支优先歌词面积，未在整合栏复刻封面与全部播放按钮；系统控制条按模式出现 |
| 网易云状态 | 通用 Now Playing 可能被其他媒体源影响 | 定向读取网易云客户端，跟随播放时间、暂停与跳转；不能保证所有版本均兼容 |
| 高清封面 | 播放器可能只给低分辨率小图 | 可选严格匹配网易云高清图；无磁盘图片缓存；匹配失败保留原图 |
| 启动 | 登录启动 | 额外可选随网易云启动，与登录启动独立，事件驱动监听 |
| 设置 | 条目密集、部分文案与独立助手状态不一致 | 控件直连实际实现、本地搜索、分组导航、外观独立页及作用范围说明 |
| 翻译 | 多处行为容易混淆 | 主窗口跟随总开关；悬浮窗“翻译与下一句”五种策略；Touch Bar 独立门控并受总开关控制 |
| 样式 | 共享设置容易误认为影响所有位置 | 字体与颜色明确主窗口/悬浮窗共用，Touch Bar 固定白色，不重复设置 |

## 本地迭代到首次公开预览

- TB.1：整合主程序控制、白色歌词、后台与全宽切换，统一时钟；增加网易云专用读取、可选高清封面与隐私说明。
- TB.2：恢复全宽时间可调，移除主程序对独立助手的依赖。
- TB.3：命名为 LyricsX TB，时间范围 1–15 秒，增加随网易云启动、本地设置搜索及矢量栏目图标。
- TB.4：核对翻译与实际控制关系，改善悬浮窗入口，删除或更正未落实/容易误解的说明。详细核查见 SETTINGS-AUDIT.md。
- TB.5：设置按用途分组；新外观页；字体与颜色统一说明，移除 Touch Bar 重复样式行。
- TB.5-preview.1：首次公开整理，加入完整来源、功能比较、构建与隐私说明；独立图标；校正遗留的绿色字体渲染测试；保留上游提交历史。

## 文案清理与保留

删除/更正“所有部位翻译都可分别设置”“自定义后仍显示固定快捷键”“高清封面适用于所有播放器”“所有动画无条件生效”等误导说法。上游下载、问题与更新检查明确标记为上游，不冒充本分支更新。未新增一个没有实现的主窗口独立翻译开关。

仍保留上游歌词来源选择、搜索、同步、缓存、悬浮窗和可选 Flexbar 等功能；本次未对所有播放器、系统版本、实体 Flexbar 或 HDR 设备完成验证，不能将本机 Touch Bar 成功推广为全设备保证。

- TB.5 发布修正：恢复上游音符图标，精简首页和发布简介；按原 LyricsX / LyricsX Next 的致谢与许可整理署名。歌词功能不变。
