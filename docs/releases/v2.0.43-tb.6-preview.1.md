# LyricsX TB.6 Compatibility Preview

同一个安装包面向 macOS 15 Sequoia 及更新系统，包含 Apple 芯片与 Intel 版本。macOS 15 的悬浮窗使用系统磨砂材质，长音辉光使用普通亮度，实时波形需要 macOS 26。Touch Bar 仍在“设置 → Touch Bar”中启用。

One universal package targets macOS 15 Sequoia and later, on Apple silicon and Intel. On macOS 15, floating lyrics use a frosted backdrop and standard-brightness glow. Live waveform requires macOS 26. Enable Touch Bar lyrics in Settings → Touch Bar.

目前为兼容试用版，未经 Apple 公证。macOS 15 与 Intel 实体 Touch Bar 的运行需要实机确认。

本地验证：macOS 27.2.1 / Apple 芯片上，完整回归的 574 项测试均通过（Flexbar 的 Node 用例补齐 PATH 后单独通过）。从 ZIP 解压后的主程序、启动助手和两个动态库均通过严格签名、双架构、最低版本和已知运行时符号检查。尚未在 macOS 15 实体机运行。
