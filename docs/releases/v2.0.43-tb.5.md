# LyricsX TB.5

基于 LyricsX Next，专注 Touch Bar 歌词体验。

- **Touch Bar**：后台歌词、全宽显示与触控切换，支持左右双语和长句滚动。
- **播放与封面**：改善网易云播放同步，支持可选高清封面匹配（仅网易云）。
- **启动与隐私**：支持随网易云启动，可选联网功能附隐私说明。
- **缓存管理**：可关闭自动缓存，支持清理缓存和查看歌词资料库。
- **设置与外观**：增加设置搜索、整理分类，完善翻译与字体颜色设置。

## 下载安装

Apple 芯片 Mac 只需下载 **LyricsX-TB-2.0.43-tb.5-arm64.zip**，解压后将 **LyricsX TB.app** 拖到“应用程序”。无需 Codex、源码包或开发工具。

## English

Based on LyricsX Next, focused on Touch Bar lyrics.

- **Touch Bar:** background lyrics, full-width display and touch switching, with side-by-side translation and scrolling.
- **Playback and artwork:** improved NetEase playback sync and optional high-resolution artwork matching (NetEase only).
- **Startup and privacy:** launch with NetEase and privacy explanations for optional online features.
- **Cache management:** optional automatic caching, cache cleanup and a lyric library.
- **Settings and appearance:** settings search, clearer categories, and improved translation and styling controls.

## Installation

Download **LyricsX-TB-2.0.43-tb.5-arm64.zip**, unzip it, and move **LyricsX TB.app** to Applications. No Codex, source code or developer tools are needed.
