# LyricsX TB 2.0.43-TB.5-preview.1

首个公开预览，基于 LyricsX Next 2.0.43 开发线（54561db8c06e1abfefbe7aa0f0c2bc26cff94eeb）。非上游官方发布；源码和现有版权声明按 MPL-2.0 保留，依赖许可随包提供。

## 主要功能与入口

- 设置 → Touch Bar：主软件直接控制歌词和后台显示；全宽及普通模式共用控制器，点歌词或两侧空白回到“歌词＋系统控制条”；闲置恢复全宽时间可选 1–15 秒。
- Touch Bar 保持 15 pt 白色常规字体；有译文时左右并列，长句独立滚动。歌词页翻译总开关及 Touch Bar 译文选项共同控制。
- 网易云专用播放信息读取，降低通用媒体源被浏览器抢占造成的“没有播放”误判；仍受系统与客户端版本兼容性影响。
- 设置 → 播放器：可选补充高清封面，按歌曲信息向网易云匹配，首次安装不启用；隐私说明及缓存边界见 PRIVACY.md。
- 设置 → 通用：可选随网易云启动，本机事件监听，不联网、不保存启动历史；首次安装不启用，与登录启动独立。
- 设置搜索、侧栏分组、新外观页；悬浮窗“翻译与下一句”的五种策略入口更明确。字体与颜色集中说明主窗口/悬浮窗共享样式，Touch Bar 不再重复。
- 统一名称 LyricsX TB，采用本项目新图标；关于页提供本分支链接并保留上游署名。

与上游的完整对比、取舍及本地 TB.1–TB.5 迭代见 [TB-COMPARISON.md](../TB-COMPARISON.md)。本栏优先歌词面积，不含上游 Touch Bar 封面及全部播放控件。

## 包与安装

`LyricsX-TB-2.0.43-tb.5-preview.1-arm64.zip`，仅 Apple Silicon，最低 macOS 26。CFBundleVersion 279.8。ad-hoc 签名，未经 Apple 公证。关闭旧版后安装；沿用 com.lyricsx.modern 设置域，不应与上游同时运行。

对应源码：本 Release 的标签快照。许可、第三方声明和构建步骤分别见 LICENSE、COPYRIGHT.md、Resources/THIRD-PARTY-NOTICES.txt、docs/BUILD-TB.md。

## 验证与限制

- 完整 Swift 测试：365 项、52 个测试组通过（--no-parallel，macOS 26.5 SDK）。包含升级介绍、设置搜索、译文策略、Touch Bar、网易云读取、封面匹配及本机 Swift/Node Flexbar 通信测试。
- 遗留渲染测试从“要求绿色文字”改为白色检查；原生 HDR 生命周期测试按真实屏幕能力限制请求值，避免在最高 2 倍余量的屏幕硬性要求 3 倍。未借此改动用户显示样式或 HDR 生产逻辑。
- 兼容性守卫自身 6 项检查通过；设置搜索索引检查及 git diff --check 通过。
- Flexbar 插件本身未修改；清单/资源验证通过。额外尝试其独立 JS 测试时因未安装 ws 等开发依赖未完成，不声称这些测试通过，也未进行实体 Flexbar 验证。
- M1 实机此前已确认白色歌词、背景显示、全宽与两侧空白切换，以及设置分组/搜索。新包仍需以最终验证记录为准。
- 不承诺所有 Intel、macOS 最低版本、HDR 显示器、播放器版本、休眠唤醒或系统更新均已验证。Touch Bar 桥接与播放信息读取依赖系统实现；歌词匹配、逐字时轴及译文质量也依赖提供商。
- 继承的歌词缓存仍存在；“高清封面无磁盘缓存”不表示整个应用不保存任何文件。在线歌词/封面查询不是完全离线。
