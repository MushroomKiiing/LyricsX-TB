# 下载与安装 / Download and install

| 电脑系统 / System | 下载 / Download |
| --- | --- |
| macOS 26+ · Apple 芯片 / Apple silicon | [TB.5.2 正式版 ZIP](https://github.com/MushroomKiiing/LyricsX-TB/releases/download/v2.0.43-tb.5.2/LyricsX-TB-2.0.43-tb.5.2-arm64.zip) |

1. 在浏览器下载列表或 Finder「下载」中找到文件。只需上表的软件 ZIP。「Source code」是供开发者使用的源码。
2. 解压 ZIP，把 **LyricsX TB.app** 拖到「应用程序」，再双击 `.app`。下载或解压不会自动安装。如果浏览器已自动解压，在下载目录直接找 `.app`。
3. 打开软件后，进入「设置 → Touch Bar」，开启「在 Touch Bar 上显示歌词」。要切到其他软件仍显示，开启「后台显示」，再播放音乐。


Download the app ZIP above, unzip it, move **LyricsX TB.app** to Applications, then open it and enable lyrics in **Settings → Touch Bar**. No Codex or source archive is needed. The packages are not notarized by Apple.
